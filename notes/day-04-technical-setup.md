# Day 4 – Technical Setup

## Objective

Install and configure the tools required to begin JavaScript and Playwright automation.

## 1. Tools and Their Purposes

- Node.js: Runs JavaScript outside a browser.
- npm: Installs and manages JavaScript packages.
- VS Code: Code editor for writing and managing automation scripts.
- Git: Tracks changes to project files.
- GitHub: Hosts repositories online.
